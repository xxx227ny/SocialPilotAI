# SocialPilot AI 复赛最终提交说明

## 1. 项目定位

SocialPilot AI 是面向跨境电商团队的 AI 社媒营销增长系统。系统以商品为唯一业务起点，把内容生产与投流优化组织为三个可演示闭环：

1. 根据商品卖点和目标平台，批量生成脚本、商品动态视频、配音、字幕和成片。
2. 为同一商品生成 TikTok、Instagram、Facebook、Pinterest 四平台文案矩阵。
3. 导入各渠道广告数据，计算 ROAS、CTR、CVR、CPA，生成预算与竞价建议，并在安全沙箱中执行、监控和回滚。

## 3. 三个目标的当前状态

### 目标 1：AI 短视频批量生产

已具备：

- 多商品、多平台、多变体批量编排。
- 千问结构化脚本和不可变脚本版本。
- 商品图片上传和内容寻址复用。
- HappyHorse 商品动态视频、千问 TTS、字幕、音乐、混音和成片链路。
- TikTok、YouTube Shorts、Instagram Reels 三平台独立进度与失败隔离。
- 成片预览、MP4/WebVTT 下载和批次 ZIP 下载。
- 批次 ZIP 在部分成功时仍可下载已有成片，并在清单中明确缺失平台。

最终验收尚缺：当前真实批次中 YouTube 和 Instagram 成功，TikTok 结果读取失败。修复必须在外部模型限流解除后使用精确批次恢复，完成三平台 `3/3` 实际播放验收。不得把 `2/3` 写成完成。

### 目标 2：AI 社媒文案矩阵

已具备：

- 千问一次生成 TikTok、Instagram、Facebook、Pinterest 四平台文案。
- 每个平台保留独立 Hook、正文、话题标签和行动号召。
- 精确商品、营销策略、文案矩阵身份恢复。
- 单平台复制、整套复制、JSON 导出、CSV 导出。
- 安全重新生成：重新确认费用、使用新请求编号、旧矩阵保留、失败不覆盖。

状态：网页端产品闭环已完成并通过专项测试和浏览器实操。

### 目标 3：AI 投流策略优化

已具备：

- CSV 广告数据导入。
- 确定性计算 CTR、CVR、CPA、ROAS，不把指标计算交给模型。
- 四平台和总体指标展示。
- 千问受约束投流建议前置检查及费用确认。
- 确定性预算分配和竞价建议。
- 沙箱执行、紧急停止、自动化上限、监控周期和回滚边界。
- 不连接、不修改真实广告账户，页面明确显示执行边界。

浏览器验收数据：商品 `#2`，4 条广告活动，总体 ROAS `2.35x`；Facebook `1.40x`、Instagram `2.00x`、Pinterest `2.60x`、TikTok `3.10x`。

状态：本地 ROAS 沙箱闭环完成。真实千问建议调用曾收到 HTTP 429，已停止且未自动重试；这属于外部限流，不冒充真实成功证据。

## 4. 技术架构与模型调用

```text
React + TypeScript 网页
          ↓ REST
FastAPI API / Pydantic Schema
          ↓
业务服务 + SQLite + Alembic
          ↓
ExecutionJob / Attempt / Worker
          ↓
阿里云 Token Plan 模型与本地 FFmpeg
```

模型职责：

| 能力 | 模型或组件 | 使用边界 |
| --- | --- | --- |
| 商品理解、策略、脚本、文案、投流建议 | 千问，运行配置为 `qwen3.7-plus` | 结构化 JSON 必须通过 Schema 校验后才能进入业务流程 |
| 商品参考图与视觉素材 | 万象图片，配置支持 `wan2.7-image-pro` | 通过受控 Provider 调用，密钥只在后端环境中 |
| 商品动态视频 | `happyhorse-1.1-r2v` | 异步提交与结果查询分离；状态不确定时禁止自动重复提交 |
| 通用文生视频备用链 | `wan2.7-t2v` | 由万象执行队列管理，需显式费用确认 |
| 配音 | `qwen-audio-3.0-tts-plus` | 语音时长进入冻结时间线，字幕按实际旁白对齐 |
| 媒体封装与质量检查 | FFmpeg / FFprobe | 本地执行，不调用云模型 |

关键安全设计：

- 所有真实模型调用默认关闭，需要后端开关、前置检查和用户费用确认同时通过。
- `ExecutionJob` 与 `ExecutionAttempt` 记录状态、调用次数和结果实体编号。
- 幂等键防止重复创建；提交状态不确定时禁止自动重试。
- 业务对象、脚本版本、素材和成品均使用精确编号，不依赖模糊的“最新记录”。
- API Key 不进入前端、数据库、日志、截图、文档或 Git。
