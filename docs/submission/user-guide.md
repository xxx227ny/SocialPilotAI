# SocialPilot AI 使用说明

## 1. 启动产品

### 后端

```powershell
cd D:\SocialPilotAI\backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

### 前端

```powershell
cd D:\SocialPilotAI\frontend
npm run dev -- --host 127.0.0.1
```

浏览器打开：`http://127.0.0.1:5173`

当前版本没有登录步骤。API Key 只保存在仓库外的安全环境文件中，不要粘贴到网页、代码、截图或聊天记录。

## 2. 页面分工

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 商品中心 | `/products` | 创建商品、品牌规范和商品素材 |
| 文案矩阵 | `/copy-matrix` | 生成、复制、导出和重新生成四平台文案 |
| 视频工厂 | `/content-studio` | 批量编排、脚本、动态画面、配音、成片、预览和下载 |
| 投流优化 | `/growth-copilot` | 导入广告数据、查看 ROAS、生成建议并运行沙箱 |

## 3. 第一次准备商品

1. 在商品中心创建商品，填写名称、品类、描述、核心卖点和目标市场。
2. 创建品牌规范及版本。推荐词、禁用词和目标地区用于约束后续文案与视频。
3. 上传清晰的商品主图。商品图应完整展示商品主体，避免过度裁切和大面积遮挡。
4. 记录网页显示的商品编号。后续页面都通过精确编号关联，不会读取模糊的最近记录。

## 4. 生成四平台文案

1. 打开“文案矩阵”，选择商品。
2. 先运行营销策略前置检查，再确认千问调用和费用。
3. 生成营销策略。
4. 运行文案矩阵前置检查并确认费用，生成四平台文案。
5. 生成成功后可以：
   - 复制单个平台文案；
   - 复制整套矩阵；
   - 导出 JSON；
   - 导出 CSV；
   - 重新生成并保留旧矩阵。

重新生成会使用新的请求编号。若网络结果不确定，页面不会偷偷重复调用千问。

## 5. 批量生成三平台视频

1. 打开“视频工厂”的批量编排区。
2. 选择商品和 TikTok、YouTube Shorts、Instagram Reels。
3. 点击“前置检查并创建”，记下页面自动显示的批次编号。
4. 等待变体达到“脚本就绪”。
5. 在真实商品视频区选择同一商品、批次和主参考图。
6. 点击“检查脚本到成片的完整调用与费用”。
7. 核对预计的千问脚本、动态视频、千问 TTS 调用数和费用区间。
8. 勾选费用确认并启动三平台完整成片。
9. 每个平台独立显示进度、失败原因、视频预览和下载链接。
10. 三个平台都完成后点击“下载批次压缩包”。

一个平台失败不会删除其他平台的结果。恢复时使用页面显示的精确批次编号，只推进未完成平台，不重新生成已成功平台。

## 6. 使用 ROAS 投流沙箱

1. 打开“投流优化”，选择商品。
2. 上传 CSV。推荐字段：平台、日期、花费、收入、曝光、点击、转化。
3. 页面会确定性计算总体和分平台 CTR、CVR、CPA、ROAS。
4. 确认营销策略、文案矩阵和视频项目编号均已就绪。
5. 运行投流建议前置检查。
6. 若需要真实千问建议，勾选费用确认后执行一次；失败后不会自动重试。
7. 设置总预算和目标 ROAS，生成内部优化方案。
8. 在广告预算沙箱中检查预算变化、竞价变化和安全上限。
9. 可启用紧急停止、自动沙箱和监控周期；这些操作不会修改真实广告账户。

## 7. 常见问题

### 按钮是灰色

通常是前置检查未通过、精确编号不匹配、费用未确认、模型开关关闭或上一步结果未完成。先阅读按钮附近的中文失败原因，不要反复点击。

### 模型返回 429

这是服务端限流或配额窗口，不代表产品数据损坏。等待限流解除后按原精确编号继续；不要创建替代批次，也不要重复已成功调用。

### 视频显示完成但无法播放

先尝试 MP4 下载链接。若下载也失败，记录平台、批次编号和页面错误；不要删除 Artifact。系统可以依据精确编号修复内容读取，而无需重新生成模型视频。

### 批次只有部分平台成功

仍可下载批次压缩包。压缩包清单会列出成功文件和缺失平台。待失败平台恢复后重新下载即可。
