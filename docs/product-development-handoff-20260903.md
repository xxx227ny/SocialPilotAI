说明：本文仅针对真实产品开发版；香港服务器上的复赛冻结版未改动。

## A. 已由开发与自动化测试完成

### 1. 独立用户与自有 API Key

- 用户可公开注册、登录、退出、修改密码、退出其他设备和注销账号。
- 每个用户自动获得独立工作区，商品、素材、任务、API Key、社媒连接和发布记录均按工作区隔离。
- 用户的阿里云百炼 Key 加密保存，只返回末四位提示；完整 Key 不进入网页响应、日志和任务记录。
- 产品模式禁止使用服务器共享 Qwen、DashScope 或 Wanx Key；没有已验证的个人 Key 时，AI 任务不能执行。
- Key 验证只读取模型列表，不生成内容；业务空间输入支持自动从完整域名提取 `ws-...` 标识。

### 2. 费用与真实进度可见

- 首页显示当前工作区真实保存的商品、素材、策略、文案、视频项目和成片数量。
- 首页显示模型调用次数、AI 任务成功/异常数量及用户已确认的预计费用。
- 费用明确标记为“预算估算，并非服务商账单”，不冒充阿里云最终账单。
- 首页显示社媒连接、发布任务、成功发布和需人工处理的发布数量。
- 上述统计全部为只读操作，不调用模型、不产生费用，也不读取其他账号的数据。

### 3. 商品创建与网络恢复

- 商品创建增加工作区级幂等保护。同一次提交即使因网络超时被重复点击，也只保存一个商品。
- 同一请求编号配合不同商品内容会被拒绝，避免错误复用。
- 商品列表、详情与常用只读接口保留有限重试和旧数据展示；写操作不会因前端重试而盲目重放。
- VPN 导致的连接关闭属于用户网络路径问题；关闭异常 VPN 后网站可恢复，不需要更换 API Key。

### 4. 视频预览与私有媒体

- Nginx 直接提供前端与静态资源，API 重启时登录页和已加载资源不再占用应用进程。
- 视频支持 HTTPS Range 分段读取、低码率 fast-start 预览、私有浏览器缓存和跨账号禁止访问。
- 本轮无付费公网媒体验收：首次预览 0.023 秒、缓存预览 0.016 秒、源视频分段读取 0.014 秒。
- 视频任务刷新、断线恢复和失败原因展示已纳入自动化门禁，不会自动重复提交付费任务。

### 5. 社媒连接与发布安全边界

- YouTube、Instagram、TikTok 和 Pinterest 的账号连接、回调校验、加密令牌存储与工作区隔离代码已具备。
- YouTube Private、Instagram Reel 和 TikTok 视频发布具备前置检查、精确任务身份、幂等保护和不确定结果保护。
- 未配置平台开发者应用、回调地址或平台审核权限时，相应入口保持禁用，不会伪装成可用。
- 不确定上传不会自动重传；真实公开发布仍需用户明确确认。

### 6. 发布、回退与数据保护

- 数据库已从 `0031_account_action_tokens` 安全升级到 `0032_product_create_idempotency`。
- 升级前后均生成数据库备份并验证数据库结构与完整性。
- 发布包现在由工具从精确 Git 提交自动生成，并强制包含前端成品、三个启动入口和非敏感发布清单。
- 临时测试账号与测试媒体在备份后精确清除；清理规则不会匹配普通邮箱。
- 开发版可以回退到前一发布目录；复赛冻结版服务和目录未被切换。

### 7. 自动验证结果

- 后端完整回归：1203 通过，9 项按设计跳过，0 失败，3 条既有依赖弃用提示。
- 前端：35 组功能门禁全部通过；产品生产构建通过。
- 公网账号冒烟：注册、登录、安全 Cookie、个人 Key、双工作区隔离、退出登录全部通过。
- 公网稳定性：连续 60 次健康检查全部返回成功。
- 公网媒体冒烟：Range、fast-start、缓存、跨账号隔离全部通过。
- 自动测试没有调用真实 Qwen、Wanx、YouTube、Instagram、TikTok 或 Pinterest，也没有产生模型/发布费用。

## B. 需要用户亲自实操的验收

建议全程关闭会拦截该域名的 VPN。预计基础验收 45–75 分钟；真实视频生成时间取决于阿里云队列，不计入操作时间。

### 1. 账号与退出流程（约 5 分钟）

1. 打开开发版地址并使用现有账号登录。
2. 点击右上角“退出登录”。
3. 预期：回到同时包含“登录、注册、忘记密码”的新版登录页。
4. 重新登录，确认商品和历史任务仍存在。

### 2. 个人 API Key（约 5–10 分钟）

1. 进入“API Key 设置”。
2. 粘贴自己的 `sk-...` Key；没有独立业务空间可把业务空间 ID 留空。
3. 如有业务空间，只填写 `ws-...`，也可粘贴完整业务空间域名让系统自动提取。
4. 点击“保存、验证并绑定”。
5. 预期：显示“已验证并启用”，页面只显示 Key 末四位。

注意：不要把 API Key、SMTP 授权码或社媒令牌发到聊天、截图或提交材料中。

### 3. 商品重复提交保护（约 5 分钟）

1. 创建一个新的完整商品。
2. 在网络较慢时快速双击一次“创建商品”，随后刷新商品列表。
3. 预期：只出现一个商品；不会因为重复点击生成多个相同记录。
4. 切换到其他页面再返回，确认商品仍可读取。

### 4. 文案生成（约 10–15 分钟，会使用个人额度）

1. 选择刚创建的商品并保存营销任务输入。
2. 先阅读模型、调用次数与预计费用，再勾选确认。
3. 只提交一次文案任务，等待完成后刷新或重新进入页面。
4. 预期：结果可以恢复，首页模型调用和预计费用随真实记录更新。

### 5. 视频生成与预览（约 20–40 分钟，会使用个人额度）

1. 选择资料和图片完整的商品。
2. 先只生成一条 15 秒视频，确认预计调用次数和费用后提交一次。
3. 任务完成后播放、拖动进度条、暂停、刷新页面并再次播放。
4. 预期：视频较快开始播放，拖动后可继续加载，刷新后仍能恢复同一成片。
5. 不要在任务状态不确定时重新提交；先使用“重新读取/刷新状态”。

### 6. 第二账号隔离（约 10 分钟）

1. 使用另一个邮箱注册第二账号。
2. 预期：第二账号看不到第一个账号的商品、API Key 提示、任务、成片和社媒连接。
3. 第二账号不绑定 Key 时，预期所有付费 AI 执行入口保持不可用。

### 7. 当前暂缓项

- 邮箱验证和忘记密码邮件：代码已完成，但按当前决定暂不配置 SMTP，因此邮件发送会明确提示服务未配置。
- YouTube、Instagram、TikTok、Pinterest 真实连接与发布：必须先在各平台开发者控制台配置应用、回调地址和权限；这部分只能由平台账号持有人实操。
- 社媒测试时先使用测试/私有发布范围。Instagram/TikTok 公开发布会产生真实外部影响，需单独确认后再做。

## 验收记录建议

实操时只需记录：步骤、时间、结果（通过/失败）、页面提示和不含密钥的截图。若出现失败，不要连续点击付费按钮；保留任务编号和安全错误提示即可。
