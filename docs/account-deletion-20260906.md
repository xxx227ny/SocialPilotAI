# 个人账号注销

入口：账号安全页面底部 → 申请注销账号 → 当前密码 + 输入“注销当前账号”。

- `POST /api/v1/auth/delete-account` 仅真实用户登录可用，不接受目标账号/工作区 ID。
- 密码二次验证、持久化尝试限流、独立个人工作区且仅一名所有者。
- SQLite 写事务内检查未结束/不确定任务，拒绝共享工作区和跨工作区关联。
- 清除在线业务记录、账号会话、邮件令牌、API Key、社交绑定与演示快照。保留匿名且停用的用户/工作区编号占位，避免旧身份编号复用。
- 保留服务器备份和离线素材文件，不宣称即时物理抹除。注销不调用外部平台，不删除已发布视频，也不自动撤销平台侧授权。
- 成功后清理前端读取缓存并返回登录页。同一邮箱重新注册获得新工作区；商品显示编号从 1 开始，需要重新验证邮箱及配置 API Key。
- 非 SQLite 数据库拒绝操作，不尝试不兼容的数据清理。

验证：账号注销与现有认证测试 26 项通过；包括错误密码、确认文字、限流、他人数据隔离、旧会话失效、重新注册、未结束任务拒绝、事务失败回滚，以及循环脚本关联在开启外键时清理。
